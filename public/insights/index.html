The B2B GEO Glossary

  • Generative Engine Optimization (GEO): The practice of optimizing digital assets for ingestion, attribution, and recommendation by AI models.
  • Answer Engine Optimization (AEO): Engineering concise, authoritative answer blocks that models can extract verbatim.
  • RAG (Retrieval-Augmented Generation): The architecture whereby LLMs query external search indexes and vector databases during inference.
  • Semantic Triples: Subject-predicate-object data structures that allow machines to parse unambiguous corporate identity.
